Tide Here

All initiatives

Purpose

2026-08-18

Make a website, at any URL today, but something cute like tidehere.info eventually. It should display upcoming tide times where the user is:

  • Standalone web page. Enter GPS location or location string. Find the location and its nearest seafront. Display the location as entered, and a standard name for the location, and the name for the nearest seafront
  • Look up and display the times of the high and low tides for the next 5 days. Display the current phase of the moon and the rising and setting times for the moon and sun for the next 5 days.
  • Improvement for version 2: have the page ask the browser for its current location and use that by default (allowing the user to override by filling in a form with GPS location)
