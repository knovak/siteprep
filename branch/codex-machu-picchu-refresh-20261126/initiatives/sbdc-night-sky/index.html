Purpose

In detail

Existing simulator, adopted with its history

SBDC Night-Sky Simulator is a standalone exploration of how a large assumed space-based data-center constellation might appear in the sky. The supplied July 2026 package includes its tutorial, specification, implementation and upgrade plans, phase reports, full source, tests, and assumptions.

The adoption preserves the working demo and all supplied material. Since 2026-11-11 there is also a beta simulator, published from its own copy of the code in beta/ on every merge. The released simulator and its source do not change when the beta does. Each copy shows "Released" or "Beta" and the date it last changed at the end of its credit line. The README describes the arrangement, and the test plan separates adoption checks from real-device testing.

The initiative remains dormant at the user's request, with no release of the beta planned. The mobile sky positioning follow-up is an optional later todo, recorded in the notes.
