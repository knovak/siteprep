Objectives

The existing tool

Let a reader explore an illustrative SBDC sky by latitude, day of year, and local solar time in a single offline HTML file. Preserve the horizon and all-sky views; twilight and Earth-shadow behavior; satellite and star counts; adjustable population, orbit families, shell altitudes, and brightness; clustering; playback; PNG export; and English/French controls described in the supplied specification and tutorial.

Keep the scenario's assumptions visible. The supplied documents distinguish geometry, illumination, and naked-eye visibility, and describe brightness and constellation architecture as assumptions. Adoption does not establish their independent scientific accuracy.

This adoption is complete when

  1. Every document, data file, and source file in the supplied archives has an unchanged destination and a SHA-256 provenance record. Archive containers retain their original size, checksum, and extracted-file inventory without requiring duplicate binary copies in the repository.
  2. All nine supplied documents are available under their original names and readable through the initiative pages, with their complete text preserved.
  3. The wish, objectives, decisions, test plan, overview, and log describe the completed tool and the current adoption scope. Historical plans stay intact.
  4. The inherited source builds to the exact supplied and current-demo HTML; the inherited tests and a browser smoke check have recorded results.
  5. The repository build passes and the branch test preview is reachable.
  6. The existing production demo remains unchanged, with real-device user testing and explicit release permission still required.

Scope

This is file adoption and documentation work. It adds no application features, rewrites no source code, regenerates no scientific datasets or golden fixtures, and changes none of the supplied documents. The user permits additions around the README only if all its contents remain available; the original is retained unchanged as well.

Future application changes, corrections to historical documents, deeper scientific review, and live ephemerides are outside this adoption. Supplied instructions to perform earlier development phases are historical material.
