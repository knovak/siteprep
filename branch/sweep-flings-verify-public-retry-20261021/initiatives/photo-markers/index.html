Purpose

2026-10-20

make a new initiative, 'Photo markers'. The purpose is to Generate a square divider image saved as a JPEG with EXIF date/time metadata so it sorts correctly inside a photo collection. It makes a divider, section marker, title card, or chapter image to insert between groups of photos.

Here are documents that provide background, and an initial implementation in python, to use as a reference. This initiative should go further, to allow the user to specify shapes and colors interactively, and to support one-at-a-time or batch delivery of images. Use the attached files as a starting point, but do not be limited by them.

The resulting web page should use WASM to do the work in the user's browser without needing a server. (That means it can deploy into the demos/ folder of this repo)
