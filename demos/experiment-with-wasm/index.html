Two working browser experiments

Two web applications.
Running locally with WASM.

WebAssembly (WASM) lets a browser run compiled software alongside JavaScript. These examples use it to query a bookmark database and calculate tides on your device. Their interfaces stay on the web; their work needs no application backend.

Static files deliver the apps. Your browser supplies the computing.

A connection delivers the website; the apps do their work locally. Downloaded files have been tested offline in Chromium on a desktop. Safari and iPad are not yet verified, and these versions do not include a Home Screen offline installation. Read the browser findings →

The starting wish

An existing website,
running on its own.

convert at least one functional web site and web UI with a wasm-based non-server application.

Bookmark Sorter was selected first because its exports were complete local inputs. Tide Here followed once its full available coastal model and an offline place catalogue were bundled.

What the experiment has shown

Read all findings →
01

Bring the software and its inputs.

WASM runs the engine. Useful offline apps also need their data, interface and supporting code available locally.

02

Keep a copy of personal data.

A saved Tide Here file includes its model. Bookmark Sorter's personal database lives separately in browser storage and needs backups.

03

Verify the whole application.

The 21 application tests cover calculations, editing, offline use and recovery. Safari, Firefox and real iPad use still need their own checks.
