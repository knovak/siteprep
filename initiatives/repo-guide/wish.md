# Wish

## 2026-08-17
I'd like a set of materials about the work process in this repository.  The reader of these materials might want to fork this repository and make own of their own; or they might want to contribute to this one, by suggesting improvements or reviewing PRs.

The work process in this repo are embedded in

- markdown files that direct agent activity
- github actions that run on merges ot other events
- various groups of test programs

A central theme should be the process around initiatives: how they're created, what their stages are, what the person and the agents are expected to supply.  There should also be a brief description of how decks are modified, and how demos are simply added to the site.

The Repo Guide should include:

- a web-based description
- a slide deck of 10-20 slides
- PDF copy of the slides
- PDF copy of the description
- a simulator of the initiative process, allowing the user to step through it and visualize it
