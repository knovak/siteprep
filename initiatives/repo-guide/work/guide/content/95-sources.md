This guide is an entry point. The files that actually drive the agents are
these:

- [AGENTS.md](source:AGENTS.md) for the working conventions: content
  vocabulary, the lifecycle table, the blocker labels, and the deployment
  rules.
- [INITIATIVES_VISION.md](source:INITIATIVES_VISION.md) for the design of the
  initiative system and the reasoning behind each choice.
- [INITIATIVES_TECHDOC.md](source:INITIATIVES_TECHDOC.md) for what the code
  does: validation, rendering, the sweep commands, and deployments.
- [initiatives/sweep-prompt.md](source:initiatives/sweep-prompt.md) for the
  exact instruction a sweep run follows.
- [BUILD_TECHDOC.md](source:BUILD_TECHDOC.md) for the site build, browser
  setup, and screenshots.
- [DEMOS_TECHDOC.md](source:DEMOS_TECHDOC.md) for the demo publishing
  contract.

Every link in this guide is pinned to the commit named in the footer, so the
linked text matches what the guide describes. For the current version, look at
the same paths on the main branch.

The guide itself is generated. Stage names, document lists, blocker labels,
the budget, the skills, and the workflows are read from the repository when
the guide is built, so those parts can't disagree with the code. The prose
around them was written by hand and dated.
