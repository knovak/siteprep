The person supplies intent, facts that exist only in their world, and authority
over consequential choices. The classes that require that input are
{{blockers.human}}. One class may receive a reasoned recommendation from the
sweep; the rest must remain visibly waiting.

Agents supply the structure around that input. They turn a wish into objectives,
compare alternatives in a specification, draft a plan and test plan, build one
bounded increment, answer review feedback, and open pull requests. The expected
documents at each point are {{lifecycle.stage_documents}}. A merge is the event
that makes proposed work part of the record; an agent never treats its own pull
request as permission to merge.

When the person answers a blocked question, the helper is described as:
{{skills.answer-decision.description}} The answer is appended to the decision
record with what it settles and what remains open. [The working vocabulary and
write rules are here](source:AGENTS.md); [the longer reasoning is here](source:INITIATIVES_VISION.md).
